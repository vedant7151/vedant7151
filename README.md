## 🌟 Featured Projects

> A curated set of my strongest, production-style builds — distributed systems, real-time platforms, and agentic AI pipelines.

### 🏦 [LedgerGrid](https://github.com/vedant7151/LedgerGrid)
`Java 21` `Spring Boot` `PostgreSQL` `Redis` `Apache Kafka` `Docker`
Distributed transaction-processing system with 3 isolated microservices, a Kafka-driven audit pipeline guaranteeing zero data loss, a SHA-256 idempotency layer, and a tamper-evident chained ledger with Redis-cached low-latency reads.

### 🛠️ [ServiceGrid](https://github.com/vedant7151/ServiceGrid)
`Java` `Spring Boot` `MongoDB` `React` `Leaflet` `WebSocket`
Constraint-based field-service scheduler built on Timefold Solver (4 hard + 4 soft constraints) cutting technician travel by 31%, with a real-time drag-and-drop dispatch board synced via STOMP/WebSocket at sub-150ms latency.

### 🚚 [RouteFlow](https://github.com/vedant7151/RouteFlow)
`Java` `Spring Boot` `MongoDB` `React` `AWS` `Docker`
Cluster-first VRP heuristic routing 20+ orders across a multi-vehicle fleet with capacity/time-window constraints, live GPS + ETA broadcasting over authenticated WebSocket, and a fully Dockerized multi-stage deployment.

### 💰 [Wealth-Wise](https://github.com/vedant7151/Wealth-Wise)
`Next.js 16` `TypeScript` `Prisma` `PostgreSQL` `Gemini AI` `Inngest`
Production-grade fintech platform with AI receipt scanning, atomic Prisma transactions for financial consistency, Inngest-orchestrated background jobs, and rate-limited, bot-protected APIs scaled for concurrent users.

### ✈️ [AI Travel Assistant](https://github.com/vedant7151/AI-Travel-Assistant)
`Python` `LangGraph` `LangChain` `FastAPI` `React`
6-agent LangGraph pipeline with dynamic conditional routing and tool-calling across 6 external APIs, plus a Critic-driven replan loop for budget/date validation exposed via FastAPI REST + WebSocket.
